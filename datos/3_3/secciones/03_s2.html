2Una aplicación lineal se determina por una base U p.114-115

Idea intuitiva

Una aplicación cualquiera es «una ley que a cada vector le asigna otro»: en principio habría que dar infinitas imágenes. Si la aplicación es lineal, no: como todo vector es una combinación de los de la base y $f$ respeta combinaciones, basta dar las imágenes de la base. El resto del espacio queda fijado «a la fuerza».

Teorema 3.2 (determinación de una aplicación lineal)

Si $f:V\to W$ es lineal y $B=\{e_1,\dots,e_m\}$ es una base de $V$, entonces la imagen de cualquier vector $v\in V$ está determinada por las imágenes $f(e_1),\dots,f(e_m)$ de los vectores de la base. Concretamente, si $v=(v_1,\dots,v_m)_B$, $$f(v)=v_1f(e_1)+v_2f(e_2)+\dots+v_mf(e_m).$$

Por qué

$v=v_1e_1+\dots+v_me_m$ (coordenadas en $B$) y $f$ es lineal (propiedad 3, U p.103): se «saca» la $f$ a cada sumando.

Ejemplo 3.16 (U) — las ecuaciones de $f$ a partir de la base canónica

$f:\mathbb R^2\to\mathbb R^3$ lineal con $f(1,0)=(1,2,1)$ y $f(0,1)=(1,1,0)$. U obtiene unas ecuaciones de $f$:

  1. Todo $x=(x_1,x_2)$ se escribe $x=x_1(1,0)+x_2(0,1)$.
  2. Por linealidad, $f(x)=x_1(1,2,1)+x_2(1,1,0)=(x_1+x_2,\ 2x_1+x_2,\ x_1)$.
  3. Llamando $(y_1,y_2,y_3)=f(x)$ a las coordenadas de la imagen: $$\begin{cases}y_1=x_1+x_2\cr y_2=2x_1+x_2\cr y_3=x_1\end{cases}$$ Son las ecuaciones de $f$: cada $y_j$ es una combinación lineal de las $x_i$, sin términos independientes.

Nota: $B=\{(1,0),(0,1)\}$ es base de $\mathbb R^2$, pero $\{(1,2,1),(1,1,0)\}$ es un subconjunto de $\mathbb R^3$ que no es base (son dos vectores en un espacio de dimensión 3): lo que tiene que ser base es el conjunto de vectores de partida cuyas imágenes se dan; sus imágenes no tienen por qué serlo.

Ejemplo 3.17 (U) — a veces los datos no son posibles

«No puede haber una aplicación lineal $f:\mathbb R^2\to\mathbb R^2$ tal que $f(2,3)=(0,1)$ y $f(-2,-3)=(1,0)$.»

  1. Como $(-2,-3)=-1\cdot(2,3)$, la linealidad obliga a que $f(-2,-3)=-f(2,3)=-(0,1)=(0,-1)$.
  2. Pero el enunciado dice $f(-2,-3)=(1,0)\neq(0,-1)$: contradicción. Los dos vectores son proporcionales (dependientes), así que no forman base y sus imágenes no se pueden elegir libremente.

Error típico

Creer que bastan «algunas» imágenes o, al revés, que «cualquier» lista de imágenes define una aplicación lineal. Para fijar $f$ hacen falta las imágenes de una base entera, y los vectores a los que se las das deben ser independientes (si no, hay que comprobar que los datos no se contradicen).
