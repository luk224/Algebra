# Algebra

Resúmenes de estudio de **Álgebra** (UNED, Grado en Ingeniería, curso 2026-27), con explicaciones para quien ve el tema por primera vez, ejercicios del libro de ejercicios resueltos paso a paso y la fuente (libro y página) de cada bloque.

**Ver online:** https://luk224.github.io/Algebra/

- `index.html` — índice de temas · `temas/` — un resumen HTML por sección
- `CLAUDE.md` — fuentes, cronograma, formato y flujo de trabajo (subagentes en `.claude/`)
- `herramientas/extraer_figura.py` — recorte de figuras de los libros
- `fuentes_txt/soluciones_*.md` — soluciones verificadas de los ejercicios

Uso personal de estudio. Las figuras y enunciados proceden de los libros citados en cada página. Se omite el resumen de la sección 1.1 (introducción a Maxima): no entra en el examen.
